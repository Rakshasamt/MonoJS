MonoJs — исходный проект с адаптивностью

Запуск: откройте index.html в браузере или загрузите всю папку на веб-хостинг.

Что изменено:
- Оригинальный файл «Site about.html», s.css, custom.css, First Var.html, шрифты, картинки, Grid.gif, Typed.js и папка Font Awesome сохранены.
- index.html — копия исходной основной страницы с подключением responsive.css и относительным путём к favicon.
- responsive.css добавляет только адаптивные правила для широких экранов, планшетов и телефонов. Основной s.css не переписывался.
- Добавлены папки assets/images, assets/videos, assets/icons, assets/fonts и assets/scripts для новых ресурсов. Чтобы новый файл появился на странице, укажите его путь в HTML/CSS (например, assets/images/photo.png).

Важно: существующие ресурсы оставлены на прежних местах, чтобы не сломать текущие ссылки. Архив содержит весь извлечённый оригинальный проект.
